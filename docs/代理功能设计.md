# 代理功能设计

## 核心能力

GoYou 优先管理本机到管理服务器 relay 的 sing-box 代理通道；旧 SSH SOCKS 通道仅作为内部兼容路径，不在登录后的用户界面展示。

## 默认代理参数

- 本地地址：127.0.0.1
- 本地端口：7890
- relay 域名：relay 域名（见 docs/敏感信息.md）
- relay 端口：24443
- relay 协议：Shadowsocks `chacha20-ietf-poly1305`
- 本地 sing-box 配置：按管理 API 返回的短期代理租约生成
- 兼容 SSH 服务器：出口服务器地址（见 docs/敏感信息.md）:12581（仅旧模式）

## 状态

- 关闭
- 启动中
- 已开启
- 关闭中
- 异常

## 诊断项

- SSH 进程是否存在
- 7890 端口是否监听
- GitHub 是否可访问
- Git 是否配置了正确代理
- 开机自启是否启用
