# “国内直连、国外代理”功能开发总结

## 1. 背景

此前 sing-box 对所有流量使用 `relay` 出口。开启系统代理后，国内网站和局域网访问也会绕行代理节点，带来访问速度下降、部分国内服务异常，以及代理节点或 DNS 故障时本地网络整体不可用等问题。

本次改造采用 sing-box 原生 `rule_set`，将中国大陆域名和中国大陆 IP 网段导向直连，其余公网目标继续通过代理节点转发。

## 2. 实施结果

路由出口如下：

| 流量类型 | 匹配方式 | 出口 |
| --- | --- | --- |
| 私有地址、局域网地址 | `ip_is_private` | `direct` |
| 中国大陆域名 | `geosite-cn` | `direct` |
| 中国大陆 IPv4 地址 | `geoip-cn` | `direct` |
| `localhost`、`.local` | 域名后缀规则 | `direct` |
| 其他公网域名/IP及未知目标 | `route.final` | `relay` |

规则按 sing-box 配置顺序执行，未命中的流量默认走 `relay`。因此，国内规则库漏收的目标会保持代理访问，不会因误判而直接泄漏到本地网络。

## 3. DNS 分流

- `geosite-cn` 命中的域名使用 `223.5.5.5`，通过 `direct` 解析。
- 其他域名使用 Cloudflare DNS-over-TLS（`1dot1dot1dot1.cloudflare-dns.com`），通过 `relay` 解析。
- DoT 地址本身由国内 DNS 解析，避免首次建立代理连接时形成 DNS 依赖环。
- DNS 默认服务器为远程服务器，未命中的域名不会使用本地 DNS，从而降低污染或劫持导致的国外站点解析失败概率。

## 4. 内置规则文件

规则文件随客户端资源一起发布，位置为 `sing-box/rules/`：

| 文件 | 用途 | 大小 | SHA-256 |
| --- | --- | ---: | --- |
| `geosite-cn.srs` | 中国大陆域名 | 55,615 bytes | `a32d727f1a71b2f9c67627ea4ae489d8d6cfb010f8ec2d6800538493fe5a77ae` |
| `geoip-cn.srs` | 中国大陆 IPv4 网段 | 34,185 bytes | `ebee603fdf402314b44b9f653cfcd6f9cc9c41e84e2b3515e3123c5c920a93bc` |

来源：

- [SagerNet/sing-geosite rule-set](https://github.com/SagerNet/sing-geosite/tree/rule-set)
- [SagerNet/sing-geoip rule-set](https://github.com/SagerNet/sing-geoip/tree/rule-set)

两个规则文件合计约 88 KB，当前采用 sing-box 二进制 SRS 格式，启动时从安装包资源目录加载。开发环境下如果资源目录不存在，会回退到仓库内的 `src-tauri/resources/sing-box/rules/`。

## 7. 已知限制与后续建议

1. 当前规则文件随客户端版本发布，规则更新需要替换资源并重新发布客户端；尚未实现运行时远程更新。
2. `geoip-cn.srs` 当前覆盖中国大陆 IPv4，IPv6 规则需要后续确认数据源和客户端兼容性后补充。
3. 国内 DNS 固定为 `223.5.5.5`。如用户网络屏蔽该地址，可增加可配置的国内 DNS 备用列表。
4. 未分类或规则库未收录的国内目标按安全默认策略走 `relay`，可通过后续规则更新减少误代理。
5. 后续如接入远程规则更新，应使用 HTTPS、版本号、SHA-256/签名校验和原子替换，并在校验失败时继续使用上一份可用规则。
