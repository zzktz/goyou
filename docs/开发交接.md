# GoYou 当前开发交接

> 本文只记录当前项目状态。历史交接材料已归档到 `temp/docs/开发交接-旧.md`。

## 项目组成

- `src/`：Tauri 桌面客户端 React 界面，负责登录、租约申请、代理状态和开关。
- `src-tauri/`：桌面命令和 sing-box/SSH 进程管理。
- `management-api/`：FastAPI + SQLite 控制面，提供客户端和管理员接口。
- `admin/`：Vue 3 + Ant Design Vue 管理后台。
- `infra/`：管理服务器 relay、真实出口 egress 和 SSH 隧道模板。
- `docs/`：当前文档；`temp/`：历史资料和构建产物。

## 当前链路

```text
GoYou 本地 sing-box
  -> relay 域名（见 docs/敏感信息.md）:24443 Shadowsocks
  -> 管理服务器 127.0.0.1:19080
  -> SSH 反向隧道
  -> 真实出口服务器 127.0.0.1:1080
  -> sing-box direct
  -> 互联网
```

客户端生产 API 地址记录在本机 `docs/敏感信息.md`。登录后获取短期租约，生成本地 `GoYou/sing-box.json` 并启动本机 sing-box。

## 继续工作前

1. 先读 [中转代理部署进度](./中转代理部署进度.md)。
2. 不要把服务器 `.env`、relay 密码、SSH 私钥或本地 sing-box 配置提交到 Git。
3. 修改管理 API 后运行 `PYTHONPYCACHEPREFIX=/tmp/goyou-pycache python3 -m py_compile management-api/app/main.py`。
4. 修改管理后台后运行 `npm run build --prefix admin`。
5. 修改桌面客户端后运行 `pnpm typecheck`、`pnpm build:renderer` 和 Rust 格式检查。
