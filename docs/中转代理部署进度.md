## 客户端 sing-box 前置条件

客户端启用代理时会执行 `sing-box run -c <用户配置目录>/GoYou/sing-box.json`。正式发行构建会自动下载并内置该可执行文件；开发机可以先安装：

```bash
brew install sing-box
```

也可以将可执行文件放在 `PATH` 中，或设置 `GOYOU_SING_BOX_PATH` 指向绝对路径。未找到 sing-box 时，客户端会显示错误，不会把新架构租约偷偷降级为直连真实出口服务器。

如果开发机不希望安装 sing-box，也可以通过构建脚本下载到 Tauri 资源目录。使用环境变量可覆盖内置二进制路径：

```bash
GOYOU_SING_BOX_PATH="/absolute/path/to/sing-box" pnpm tauri dev
```

`src-tauri/resources/sing-box` 下的二进制由 `pnpm run prepare:sing-box` 生成并被 Git 忽略；发行包会通过 Tauri resources 将它带给最终用户。
