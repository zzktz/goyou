# GoYou 项目说明

## 项目定位

GoYou 由 Tauri 桌面客户端、管理 API、管理后台和中转基础设施组成。桌面端负责用户登录和本机代理开关，管理 API 负责认证与租约，管理后台负责运维查看和撤销操作。

## 运行入口

- 桌面客户端：`pnpm tauri dev`
- 管理后台和 API 地址：见本机 `docs/敏感信息.md`（不提交到 Git）

## 项目来源

- 基座来源：历史 `switch` 项目迁移，旧资料已归档到 `temp/`。
- 当前主开发目录：本仓库根目录。
- 远端仓库：`git@github.com:zzktz/goyou.git`

## 目录约定

- docs/：只放中文简体文档
- temp/：放历史资料和可重复生成的构建产物，不参与构建和部署

## 当前目标

- 一键开启 / 关闭本机 sing-box 代理
- 登录后获取短期代理租约
- 管理用户、租约和节点状态
- 提供 GitHub 连通性诊断
