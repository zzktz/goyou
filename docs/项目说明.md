# GoYou 项目说明

## 项目定位

GoYou 由 Tauri 桌面客户端、管理 API、管理后台和中转基础设施组成。桌面端负责用户登录和本机代理开关，管理 API 负责认证与租约，管理后台负责运维查看和撤销操作。

## 运行入口

- 桌面客户端：`pnpm tauri dev`
- 管理后台和 API 地址：见本机 `docs/敏感信息.md`（不提交到 Git）

## 客户端正式版发布

客户端正式版的 macOS、Windows 编译和发布由 GitHub Actions 自动完成，不需要在本机编译正式安装包。发布新版本时，更新客户端版本号后提交代码，并将对应的 `vX.Y.Z` 版本标签推送到远端仓库；GitHub 会自动执行正式版构建、签名配置和 Release 发布。

```bash
git add .
git commit -m "发布 v1.0.39"
git push origin main
git tag v1.0.39
git push origin v1.0.39
```

正式版发布工作流位于 `.github/workflows/release.yml`，由推送 `v*` 标签触发。

- docs/：只放中文简体文档
